# Hospital Management System 🏥

A web-based application designed to manage hospital activities efficiently. This project uses a **Local Database (IndexedDB)**, meaning all data is saved directly in your browser.

## 🚀 Features
* **Patient Records**: Add and view patient data.
* **Local Storage**: Uses IndexedDB, so no external server is needed.
* **Responsive Design**: Built with Bootstrap for mobile and desktop support.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, Bootstrap
* **Logic**: JavaScript (ES6+)
* **Database**: IndexedDB (Browser Local Storage)

## 📂 How to Run
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
